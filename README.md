
# Sensor Dashboard: ZMQ Server & Remote Control

Это приложение — панель управления (Backend GUI) для визуализации данных с датчиков (Android). Оно использует **ZeroMQ** для надежной передачи данных и **Dear ImGui** для интерактивного интерфейса.

1. **Переход на ZeroMQ (REQ-REP):** Отказ от сырых TCP-сокетов в пользу надежного обмена сообщениями.
2. **Двустороннее управление:** Сервер не просто принимает данные, а отправляет команды фильтрации обратно на Android-устройство.
3. **Умная фильтрация:** В интерфейсе добавлены чекбоксы. Если выключить передачу параметра (например, высоты), Android-приложение перестанет присылать это поле, экономя трафик.
4. **Sparse JSON:** Сервер корректно обрабатывает пакеты с отсутствующими данными, предотвращая ошибки парсинга.

## Функциональность

* **Sensor Data Window:** Отображение координат и времени в реальном времени.
* **Control Settings Window:** Вкладка с фильтрами (`Checkbox`), управляющая логикой отправки данных на стороне смартфона.
* **Статус подключения:** Визуальная индикация активности входящих данных.

## Требования

* Компилятор с поддержкой **C++17**.
* Библиотеки:
* **ZeroMQ** (libzmq) и **cppzmq** (заголовочные файлы).
* **SDL2** и **GLEW**.
* **nlohmann/json**.



## Установка зависимостей (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install build-essential cmake libsdl2-dev libglew-dev libgl1-mesa-dev nlohmann-json3-dev libzmq3-dev

```

## Сборка и запуск

```bash
mkdir build && cd build
cmake ..
make
./main

```

## Протокол обмена

### Android -> Server (Data)

Отправляет JSON. Если фильтр активен, поле передается, если нет — поле отсутствует.

```json
{
  "_Latitude": 55.018,
  "_Longitude": 82.952,
  "_Time": 1772268444506
}

```

### Server -> Android (Command)

В ответ на каждый пакет сервер отправляет текущее состояние фильтров из GUI:

```json
{
  "f_lat": true,
  "f_lon": true,
  "f_alt": false
}

```
